# 教师资源广场原型：NarrativeOS 视觉落地约束

2026-10-31。此文件约束本原型的后续实现。

原型用于确定分类层级、布局、作品信息顺序与抽卡交互。正式实现使用 NarrativeOS 已有组件和视觉变量；不得整体复制参考站样式，也不得把演示代码中的历史 CSS 覆盖层直接搬入产品。

## 视觉依据

广场实际归属 linchangWeb，采用 src/app/globals.css 的品牌变量：纸色 #f3ede1、柔纸 #faf7ef、深纸 #e8dfcd、墨色 #262019、次墨 #453c32、淡墨 #7d7367、线色 #d8cdbb、朱红 #9c3340、深朱红 #70222e、浅朱红 #f2dfe0、金色 #b18c45。Forge 的 globals.css 是同品牌另一套变量，正式迁移时应使用目标应用自己的变量，避免额外创建第三套色板。

中文标题使用现有衬线字体栈，正文使用 Noto Sans SC / PingFang SC / Microsoft YaHei UI。NarrativeOS 字标使用 Forge 已有 narrativeos-solution-title.ttf；原型本地复制字体仅用于预览。品牌方印沿用广场现有“临”，不是另创新标识。

主按钮、选中态和重要动作使用朱红；米纸、墨色、淡金边线构成界面主体。矿物绿只可用于插画，不作为全站操作主色。中文信息为主，避免把参考站英文编号和创业主题当成品牌文案。

## 已确认的交互几何

横向教学卡片；两行标题槽确保同一行内容对齐；卡片底部紧凑。磨砂层静止高 28.5px，浮起时高 19px；小屏相应为 27.5px / 18.333px。卡片上浮 24px。作者行在磨砂后，上浮时露出。不要因换肤重新改变这些已反复调整的参数。磨砂语汇仅保留在卡片收纳层、固定导航与详情遮罩。

## 实现边界

现有示例图片、作品、数量、教学流程均为设计占位，不是已验证业务信息。正式接入按实际封面、权限和内容呈现。保留布局与交互意图，重新整理组件与 CSS，复用目标仓库的按钮、反馈、对话框与字体，不复制本单文件不断追加的样式覆盖。
